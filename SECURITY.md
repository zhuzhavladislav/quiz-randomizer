# Security policy

QuizRandomizer is an offline desktop app: it opens no network connections and only reads
files the user picks explicitly. Still, if you find a vulnerability (for example in how
preset archives or asset files are handled), please do not open a public issue.

Report it privately via [GitHub security advisories](https://github.com/zhuzhavladislav/quiz-randomizer/security/advisories/new)
or by e-mail to vladislav.zhuzha@gmail.com. You will get a reply within a week.

Only the latest release is supported.
