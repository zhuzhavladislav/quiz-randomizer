# QuizRandomizer

[English version](README.md)

Десктопное табло для розыгрыша случайного числа на квизах, барных играх и лотереях.
У ведущего компактное окно настроек, на втором экране огромная крутящаяся цифра.
Полностью офлайн.

![Табло](docs/board.png)

## Возможности

- **Табло на втором дисплее** - открывается во весь экран на втором мониторе
  автоматически (или на выбранном), без второго монитора - обычное окно.
- **Барабан** - результат выбирается заранее, табло крутит числа как барабан и
  замедляется к концу. Четыре вида анимации или случайная.
- **Команды** - список по одной на строку: диапазон становится 1…N, под выпавшим
  числом появляется название команды.
- **Без повторов** - выпавшие числа исключаются до сброса; история видна в окне
  настроек и в углу табло.
- **Пресеты оформления** - шрифт (любой системный с поиском и предпросмотром или файл),
  цвета, тень цифр, цвета конфетти, паттерн на фоне и логотип. Пресеты хранятся
  локально, экспортируются и импортируются одним файлом `.rpreset` вместе со шрифтами
  и картинками.
- **Два языка** - русский и английский интерфейс, определяется по системе (переключатель
  в секции «Приложение»).
- Клавиши: `Пробел` / `Enter` запускают розыгрыш из любого окна, `Esc` выходит из
  полного экрана, `F` или двойной клик переключает его. Окно настроек можно держать
  поверх всех окон.

## Скачать

Инсталляторы для Windows (`.exe`) и macOS (`.dmg`, Apple Silicon и Intel) приложены
к каждому [релизу на GitHub](https://github.com/zhuzhavladislav/quiz-randomizer/releases).

Сборки не подписаны. На macOS при первом запуске правый клик по приложению → «Открыть»;
на Windows в SmartScreen «Подробнее → Выполнить в любом случае».

При обновлении с версии 1.0 (приложение «QuizNaBis Randomizer») настройки, пресеты и
файлы переносятся в новую папку данных автоматически.

## Как это работает

1. Задайте диапазон (или вставьте команды), длительность прокрутки и нажмите **Старт**.
2. Main-процесс выбирает результат через `crypto.randomInt`, отправляет его табло, табло
   крутит числа к нему. Победитель объявляется через секунду после остановки барабана:
   цифра пружинит, падает конфетти, результат уходит в историю.
3. Пресеты лежат в `presets.json` в папке данных приложения; файлы пользователя (шрифты,
   картинки) копируются в `userData/assets` и раздаются табло по внутренней схеме
   `asset://`, рендерер остаётся в песочнице. Пресеты из `presets/` импортируются
   автоматически при первом запуске.

## Разработка

Нужен Node.js 22.12+ (см. `.nvmrc`).

```bash
npm install
npm run dev        # оба окна с hot reload
npm run typecheck
npm run build      # сборка в out/
npm run dist       # инсталлятор для текущей ОС в release/
```

Стек: Electron + React + TypeScript + Vite (electron-vite), упаковка electron-builder.
Включены `contextIsolation` и `sandbox`, рендерер общается с main только через
типизированный мост в `src/preload`.

```
src/main/       main-процесс: окна, дисплеи, IPC, настройки, пресеты, схема asset://
src/preload/    типизированный мост window.api
src/renderer/   control.html (окно ведущего) и board.html (табло), React
src/shared/     типы, модель темы, словари i18n
presets/        пресеты из комплекта (.rpreset), импортируются при первом запуске
build/          иконка приложения
```

### Релиз

Push тега `v*` собирает инсталляторы на GitHub Actions и прикладывает их к релизу:

```bash
npm version minor -m "v%s" && git push --follow-tags
```

### Участие

Issues и pull requests приветствуются. Окно настроек держим минималистичным, табло
читаемым с другого конца бара; строки интерфейса добавляются в `src/shared/i18n.ts`
на обоих языках.
